# Claude Game Helper

A Windows tray app that runs Claude Code as a sidecar while you play games: hotkeys capture the game
screen or take a typed question, and answers appear in a side panel over the game. Any game gets a profile
automatically; Fallout 76 ships with hand-tuned instructions. Shared through a Velopack installer on
GitHub Releases (see [README.md](README.md)).

**Starting a new session? Read [docs/HANDOFF.md](docs/HANDOFF.md) first.** It has the current status,
the next steps, facts about the owner's PC, and how Jason likes to work.
